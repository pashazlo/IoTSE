# Instructions for Codex

Прежде чем менять проект, полностью прочитай `README_CODEX.md` в корне репозитория. Он содержит назначение устройства, текущую архитектуру, проверенное поведение, технический долг и порядок завершения FM worker/mini-IDE.

Обязательные правила:

- Сначала сверь README с фактическим деревом, `git status`, веткой и текущей сборкой.
- Сохраняй уже проверенное поведение FM, клавиатуры, popup и прокрутки.
- Делай одно небольшое проверяемое изменение за раз.
- UI не выполняет долгие файловые или аппаратные операции.
- Не смешивай миграцию FM worker, редактор, DMA и общий focus в одном изменении.
- Не оставляй дубли `.c` в каталогах с `GLOB_RECURSE`.
- Проверяй коды ошибок, границы строк, владение состоянием и время жизни DMA-буферов.
- После каждого изменения отчитайся: поведение, файлы, причина, проверки, сценарий на плате, оставшиеся риски.
- Различай host-тест, сборку ESP-IDF и реальную проверку на ESP32-S3.
- Предлагай полезные архитектурные и UX-улучшения, но отделяй предложения от уже внесённого кода.

Текущий приоритет: завершить FM worker безопасными вертикальными шагами, затем сделать удобную mini-IDE. Не начинай новую периферийную функцию, пока текущий шаг не доведён до проверяемой рабочей точки.
